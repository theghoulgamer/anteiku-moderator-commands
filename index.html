🛡️ Moderator Commands

A quick reference for AnTeiku moderators. Use these commands responsibly and follow the channel's moderation guidelines.

Moderator reference: This page lists commands found in the supplied Streamer.bot export. The export marks these command entries as disabled, so check with the broadcaster before relying on any command being active. Command permissions and required arguments are not specified in the export.
ShoutoutsLoyalty PointsRaffleViewer Shoutouts

📣 Better Shoutouts

Shoutout

Runs the Better Shoutouts command.

!so!shoutout

💰 Loyalty Points Management

Add points to present viewers

Add points to viewers currently present in chat.

!addToAllPresent!addPointsToAllPresent!addPointsToPresent!addToViewers!addPointsToViewers
Add points to all users

Add points across all users in the loyalty system.

!addToAllUsers!addPointsToAllUsers
Add points to one user

Add loyalty points to a specified user.

!addPoints!pointsAdd
Collect taxes

Runs the loyalty points tax collection action.

!collectTaxes!taxesCollect!taxCollection
Enable Happy Hour

Enables the loyalty points Happy Hour action.

!pointsHappyHour
Remove points from one user

Remove loyalty points from a specified user.

!removePoints!pointsRemove
Multiply all users' points

Runs the points multiplier action for all users.

!multiplyAllUsersPoints
Start Rumble

Starts the loyalty points Rumble action.

!rumble
Transfer points

Runs the loyalty points transfer action.

!givePoints!pointsGive!transferPoints!pointsTransfer

🎟️ Raffle Management

Force-end raffle

Runs the raffle force-end command.

!raffleend
Start raffle

Runs the raffle V2 command.

!raffle
